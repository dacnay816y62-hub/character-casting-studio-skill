# Material Reference Library

Read this catalog when a character request needs a distinctive film, commercial, fashion, or model identity. These images are visual sources, not identity targets.

## Usage Rules

- Use at least three source categories for production-grade characters: face structure, styling/body/pose, and world/light/material.
- Assign different face sources to different characters in a batch. Do not feed the whole library as one undifferentiated face prompt.
- Extract broad genes only: face geometry, eye and brow structure, hair behavior, skin texture, age cues, expression, silhouette, and lighting.
- Never copy a single person's identity, exact facial arrangement, signature styling, or recognizable likeness.
- For a batch, build an identity matrix and state that the characters are distinct unrelated individuals.
